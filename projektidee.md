# Projektidee: HabitQuest

## Grundidee

- User kann Habits erstellen
    - Bspw. Joggen, Lesen, Lernen
- Habits können regelmäßig (Wöchtenlich, Täglich, Monatlich) als erledigt markiert werden
    - Werden diese Dauerhaft erFüllt entstehen Streaks die Bonus XP geben
- Für jede abgeschlossene Habit erhält man XP
    - XP füllen Level für Belohnungen wie Titel, etc.
- Alternativ kann eine ChatGPT-API angesprochen werden die dynamisch XP verteilt
- Alle Daten werden in einer Datenbank gespeichert
    - ChatGPT bekommt dynamisch Zugriff auf die Datenbank und kann somit Daten speichern

### Rollen

- User
    - Normales UI
    - Kann Habits erstellen
    - Kann Habits bearbeiten
    - Kann erhaltene Belohnungen einsehen
- Maintainer
    - Erweitertes UI - Kein reguläres UI
    - Kann Belohnungen erstellen
    - Kann Events/Heruasforderungen erstellen

### Optional

- Angepasste XP
    - Wenn ich jeden Tag 10km Jogge muss ich mich irgendwann steigern
    - ggf. Muss Anstrengung/Aufwand angegebene werden
